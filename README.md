# 魔方模拟器使用说明

## 概述
这是一个3D魔方模拟器，支持标准的3x3x3魔方操作，包含完整的CFOP求解算法。通过键盘输入可以控制魔方旋转、打乱和自动求解。

## 基础控制

### 基本旋转操作
- **L** - 左层面顺时针旋转
- **R** - 右层面顺时针旋转  
- **U** - 上层面顺时针旋转
- **D** - 下层面顺时针旋转
- **F** - 前层面顺时针旋转
- **B** - 后层面顺时针旋转
- **M** - 中间层（垂直中层面）顺时针旋转
- **E** - 水平中层面顺时针旋转
- **S** - 侧中层面顺时针旋转
- **X** - 整个魔方绕X轴旋转
- **Y** - 整个魔方绕Y轴旋转
- **Z** - 整个魔方绕Z轴旋转

### 修饰键控制

#### 方向反转
- **Shift (左或右)** - 按住时旋转方向变为逆时针
  - 默认：顺时针旋转
  - 按住Shift：逆时针旋转

#### 旋转角度
- **Space (空格)** - 按住时旋转角度变为180°
  - 默认：90°旋转
  - 按住空格：180°旋转

#### 双层旋转
- **Ctrl (左或右)** - 按住时进行双层旋转
  - 默认：单层旋转
  - 按住Ctrl：双层旋转（如l、r、u、d、f、b）

## 特殊功能

### 魔方打乱
- **Tab** - 随机打乱魔方（17步随机旋转）

### 自动求解
- **0 (数字键0)** - 使用CFOP算法自动求解魔方

## 操作示例

### 单层旋转
- 按下 `U` - 上层面顺时针旋转90°
- 按下 `Shift + U` - 上层面逆时针旋转90°
- 按下 `Space + U` - 上层面顺时针旋转180°
- 按下 `Shift + Space + U` - 上层面逆时针旋转180°

### 双层旋转
- 按下 `Ctrl + U` - 上两层顺时针旋转90°
- 按下 `Ctrl + Shift + U` - 上两层逆时针旋转90°

### 中间层旋转
- 按下 `M` - 垂直中间层顺时针旋转90°
- 按下 `E` - 水平中间层顺时针旋转90°

### 整体旋转
- 按下 `X` - 整个魔方绕X轴旋转90°
- 按下 `Y` - 整个魔方绕Y轴旋转90°
- 按下 `Z` - 整个魔方绕Z轴旋转90°

## 注意事项

1. **旋转队列系统**：所有旋转操作都会被加入队列，当前一个旋转完成后才会执行下一个
2. **旋转速度**：根据队列中等待的旋转数量，旋转动画速度会变化：
   - 2个以下：慢速（0.2秒）
   - 3-5个：中速（0.17秒）
   - 6个以上：快速（0.15秒）
3. **自动求解**：只有在没有旋转正在执行且队列为空时，才会开始自动求解
4. **求解步骤**：CFOP求解分为四个阶段：十字、F2L、OLL、PLL
